## 00:15 UTC — UC-U43: adjacent hunk refinement and rename detection

The UC-U42 leftover (adjacent changes conflict like git; no rename/move
detection) is the only named gap after 69/69 Verified. Specified and
implemented as UC-U43.

- **Hunk refinement** (`diff3.go` `refineGap`/`mergeHunks`): when coarse
  diff3 has a conflicting gap (no three-way anchor inside it), pairwise
  LCS hunks of that gap are applied independently if their base ranges do
  not overlap. An insertion at index `i` does not overlap a replacement of
  `[i,j)`. Competing inserts at the same index still conflict.
- **Rename match** (`rename.go`): 1–1 unique-best pairing of a deleted base
  path with an added path at ≥60% line-LCS similarity. The ordinary content
  merge then runs and both sides are rewritten so the file-level merge sees
  the new path. Ties, sub-threshold pairs, destination collisions, and
  divergent destinations are left as delete+add / modify-delete.
- No new CLI verb: a rename is a snapshot-level delete+add. Tests drop the
  old file vertex with the existing `removeVertexAndEdges` helper.

Layering stays structural → diff3 → this refinement. Language gate and
go/types gate (UC-U40) still run; `--ours`/`--theirs` still resolve
genuine overlaps.

Honest limits recorded on the UC: no copy detection, no basename-weighted
scoring, no unification of two different rename destinations.

## 00:35 UTC — UC-U43 review of #71 (mode, edges, LCS cap, rational ties)

Four defects from Codex/Copilot on the rename pre-pass:

- Mode is a three-way merge against base + both sides (dest if that side
  renamed, else old path). A 0644 rename + 0755 chmod keeps 0755. Divergent
  modes leave the rename unapplied.
- `removeFileAtPath` still drops only the vertex; `retargetIncident` then
  rewrites incident edges/hyperedges to the dest id so `Snapshot.Build`
  stays well-formed.
- Rename scoring no longer calls `lcsMatch`. `lcsLen` is two-row
  (linear memory); pairs with `n×m > 2e6` use bag-of-lines overlap. Diff3
  still uses `lcsMatch`.
- `uniqueBest` compares `shared/maxLen` by cross-multiply. 3/5 vs 6/10 is
  a tie and refuses.

Gates and `--ours`/`--theirs` unchanged.
